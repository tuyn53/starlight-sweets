# 甜星大作战 · SWEET STAR BLITZ · 开发流程文档

> 用途：换电脑后按本文档即可继续开发。项目是纯静态 H5 游戏，无构建、无依赖安装，重点在「改哪里、怎么验证、美术怎么生产、怎么部署」。
> 最后更新：2026-11-18

## 1. 项目一句话

Q 版卡通可爱风的类吸血鬼幸存者 H5 游戏：虚拟摇杆移动、星光自动攻击、拾取星星升级三选一、20 关逐关解锁，每 5 关一位甜点主题 Boss，4 幕场景（阳光草地 / 糖果森林 / 云端天空 / 星光城堡）。原生 Canvas 2D + classic script，nginx 静态托管。

## 3. 代码结构与职责

### 3.1 文件职责

| 文件 | 职责 | 改动频率 |
|---|---|---|
| `js/config.js` | 所有数值与数据表：`CFG`、`WEAPONS`、`PASSIVES`、`ETYPE`、`ACTS`、`BOSSES` | 最常改，调平衡只动这里 |
| `js/core.js` | 画布/DPR、工具函数、`Juice` 震屏手感、`Sound` 音效、`Input` 摇杆/键盘 | 少 |
| `js/music.js` | BGM：8 小节可爱循环曲的程序化合成、lookahead 调度器、音乐开关 | 少 |
| `js/rig.js` | 动作状态机：采样摆腿/挥手/呼吸/受击的关节角度（只算数值，不画）；大厅与游戏共用 | 少 |
| `js/slicerig.js` | 纸娃娃切片骨骼：把原 AI 精绘 PNG 切成躯干+四肢，绕关节旋转，**画风不变但手脚能动**（`CFG.USE_SLICE`） | 少 |
| `js/sprites.js` | AI 精灵预加载 `loadSprites()` / `drawSprite()`，切片未就绪时回退静态图 | 少 |
| `js/logic.js` | 游戏状态机、关卡流程、刷怪、伤害、8 种怪物机制、选敌优先级、胜负判定 | 核心玩法改动 |
| `js/render.js` | 全部绘制：4 幕场景、技能特效、敌人/玩家、HUD；精灵优先、`drawChibi` 兜底 | 视觉改动 |
| `js/main.js` | 主循环（固定步长+插值）、关卡选择、Q 版首页、星光转场、事件绑定 | 入口/界面交互 |
| `index.html` | DOM 结构：HUD、首页舞台、选关、升级卡、结算、转场层 | 结构性改动 |
| `style.css` | 全部样式与动效；文件后半是 Q 版首页专属段 | UI 改动 |

### 3.2 加载顺序（不可调换）

`index.html` 底部按以下顺序加载，classic script 共享全局作用域，顺序就是依赖关系：

```
config.js → core.js → music.js → rig.js → sprites.js → slicerig.js → logic.js → render.js → main.js
```

`music.js` 依赖 `core.js` 的 `Sound`（复用 AudioContext）；`rig.js` 提供动作采样值；`slicerig.js` 依赖 `sprites.js` 的原图并调用 `Rig.sample`。三者都要在 `render.js`/`main.js` 之前。

**禁止**把代码合回单个 HTML 文件（明确决策过：最终走 nginx 多文件静态资源）。

## 4. 开发原则（踩过坑换来的）

1. **关键决策先讨论再动手**：玩法骨架、美术方向、命名这类大改动，先给方案确认，不要直接写代码。
2. **内部 type key 永远不改**：敌人用 `spore/swift/split/mimic/thief/bomber/elite/boss`，改名只改显示名（`ETYPE[type].name`），否则选敌、击杀、Boss 流程全断。
3. **整体风格锁死 Q 版明亮可爱**：不接受暗黑配色/文案；技能是星光系，敌人是甜系娘化。
4. **移动端是第一目标**：任何 UI 改动必须检查 390×844 竖屏和 667×375 横屏；升级三卡必须横排不裁切。
5. **可访问性是功能不是附加**：震屏/闪光三档开关、`prefers-reduced-motion` 降级、文字最小 14px、触摸目标最小 44px。
6. **程序化绘制是兜底不是废弃物**：`render.js` 的 `drawChibi` 系列在精灵图缺失时保证游戏可玩，改机制时两条路径都要兼容。

## 5. 常见改动指南

### 5.1 调平衡 / 改数值
只动 `js/config.js`：
- 关卡循环：`CFG.LEVEL`（`playerMax` 满级目标、`diffStep/diffTime/diffLv` 敌人成长、主题 Boss 与关底守卫血量 `bossHpBase/Step`、`guardHpBase/Step`、`bossSequence` 演出时长）。**满级触发关底，不再有存活/击杀过关判定。**
- 刷怪模型：`CFG.SPAWN`（`targetBase/targetPerLv/targetCap` 目标存活数、`refillPerSec` 每秒补怪数）与 `UNLOCK_TABLE`（每关怪池 + `density` 密度系数）
- 经验曲线：`CFG.XP_BASE / XP_GROW`（满级总需经验 ≈800）
- 场景：`CFG.ACTS`（4 幕的 `ground/groundAlt` 地面色 + 装饰类型）
- Boss：`CFG.BOSSES`（第 5/10/15/20 关主题）
- 震屏抗眩晕：`CFG.FEEL`（`hitCap/hitGap/shakeMax/traumaDecay`，动之前先看第 9.4 节踩坑）
- 棉棉平衡：`CFG.SPORE`（幼体保护期、糖霜云半径/伤害/上限）

### 5.2 加/改武器
1. `config.js` 的 `WEAPONS` 加数据（伤害/冷却/等级成长）。
2. `logic.js` 攻击逻辑（单体走 `pickTargets`，范围伤害直接结算）。
3. `render.js` 画特效，风格必须星光系（星光弹/星环/彩虹结界/流星/星爆）。
4. 升级卡池若要出现新武器，检查 `PASSIVES`/卡牌构建逻辑。

### 5.3 加/改怪物机制
1. `config.js` 的 `ETYPE` 加条目：属性 + `mech` 机制字段 + 甜系显示名。
2. `logic.js` 实现机制（参考现有 8 机制：糖霜云/突进/分裂/隐身/偷经验/自爆/召唤/Boss 三阶段）。
3. `render.js` 加程序化兜底绘制。
4. 手脚动画走切片方案：在 `slicerig.js` 的 `CUT` 里为该 type 配四肢切割区（或用 `_default`），新怪自动继承摆腿/挥手。切割位置参考 `scripts/` 里的 PNG alpha 扫描思路——切区比挖空区大一圈，根部留余量盖缝隙。
5. 静态精灵图走第 6 节美术管线；切片用的就是这张原图，画风不降级。
6. 跑 `smoke_test.js`，并补新机制的断言。

### 5.4 改 UI / 首页
- 结构改 `index.html`，样式动效改 `style.css`（Q 版首页段在文件末尾，有清晰注释分区）。
- 首页转场统一走 `main.js` 的 `transitionTo(fn)`，不要直接 `show()/hide()` 生切。
- 转场中点约 240ms 执行目标动作，总时长 720ms；`prefers-reduced-motion` 下会自动跳过。

## 6. 美术资产管线（AI 生成精灵）

### 6.1 契约先行

任何生图前先读 `docs/art-direction-brief.md`，它是唯一视觉标准：
- Q 版二头身（头身比约 1:1.2）、正面 5-10° 俯视、全身、脚底贴画布底边
- 左上柔光、3 段明度、深色描边 `#070a16`
- 512×512 **真透明** PNG，静态中性 pose，禁止预画动作/特效/文字
- 每角色一个专属配饰保证 44px 下剪影可辨

### 6.2 生成与归一化流程

```bash
# 1. 用 ImageGen 按契约提示词生成，原图存入 _source/
#    （公共锁定块 + 角色 CHARACTER_BLOCK，见 art-direction-brief 第 3 节）

# 2. 归一化：去假透明背景、去右下水印、裁切、缩放 512² 真 RGBA
python3 scripts/make_sprite.py \
  "assets/characters/_source/原图.png" \
  "assets/characters/目标名.png" 512 --watermark

# 3. 游戏实际尺寸验收（玩家 30px / 普通怪 44px / 精英 52px / Boss 104px）
python3 scripts/preview_scale.py assets/characters/目标名.png /tmp/preview_44.png 44 --bg grid

# 4. 目视检查后替换正式文件，浏览器刷新即可（sprites.js 自动加载）
```

### 6.3 验收门槛
- 背景真透明、无白边光晕、无水印残留
- 头顶/脚底/配饰无裁切
- 缩到实际游戏尺寸后剪影和专属配饰仍可辨
- 更新 `assets/manifest.json`（来源、验收状态）
- 生成的原图永远留在 `_source/` 溯源

已知限制：ImageGen 常给**假透明棋盘格**和右下「AI生成」水印，`make_sprite.py` 已专门处理；Pillow 在部分环境装不上，所以脚本坚持纯标准库，不要改成依赖 Pillow。

## 8. 部署

纯静态，整目录丢进 nginx root 即可。关键配置：

```nginx
server {
    listen 80;
    server_name your-domain.com;
    root /path/to/ai_test;
    index index.html;

    include /etc/nginx/mime.types;   # 必须有！
    default_type application/octet-stream;

    location / { try_files $uri $uri/ =404; }
}
```

```bash
nginx -t && nginx -s reload
```

**最高频翻车点**：漏 `include mime.types` 时 CSS 以 `text/plain` 返回，Chrome 拒绝加载，页面只剩 Canvas 没有 UI。JS 是 classic script 不受影响，所以现象是「能玩但没界面」，别去查 JS。

## 9. 关键设计决策与踩坑速查

### 9.1 玩法骨架（2026-11-19 关卡循环改造后）
- **每关 = 一次完整的 Lv1→Lv20 单局**，第 1 关与第 20 关起手完全一致（Lv1 + 星芒一把）；关卡之间不继承任何数值，跨关成长只靠卡池/怪池/场景解锁
- **满级触发关底**：升到 Lv20 → 清场演出（`bossSequence` 秒）→ 关底降临 → 击杀过关。旧的"存活+击杀双目标"与"开场 2.2 秒出 Boss"已废弃
- **每关都有关底**：5/10/15/20 为主题 Boss（三阶段、血量 `bossHpBase+Step×关`，L20≈15000）；其余 16 关为关底守卫（复用 boss 图 + 按幕 hue 染色，两阶段无激光、血量 `guardHpBase+Step×关`，L20≈6800）
- 刷怪 = 维持屏幕数量模型（`22+等级×3`，上限 80，每秒最多补 6 只），怪池查 `UNLOCK_TABLE` + 关内按时间分波次；满级后经验球转微量回血
- 关卡难度靠关号主导的敌人成长 + 逐关扩充怪池，不再靠起跑线白送属性
- 进度 key：`localStorage.starlight_guard_progress`（只存解锁关号，不存中间态）
- 通关状态机：`playing → clear/gameover`，`clear` 立即切、结算面板延迟弹出；满级演出用游戏内计时 `bossSeqT`（不用 setTimeout，暂停不错乱）
- 待校准：按当前 XP 曲线，理想击杀率下满级约 2-4 分钟，短于设计目标 8-10 分钟，需 3 次实机试跑后微调 `XP_GROW`/击杀率

### 9.2 命名对照（内部 key → 甜系显示名，只改显示名）

| key | 显示名 | 机制 |
|---|---|---|
| spore | 棉棉 | 糖霜云（22s 幼体保护期） |
| swift | 跳跳 | 突进 |
| split | 团子 | 分裂 |
| mimic | 果冻 | 周期隐身 |
| thief | 焦糖 | 偷星星经验 |
| bomber | 爆米 | 贴身自爆 |
| elite | 泡芙 | 精英，召唤 |
| boss | 莓莓/抹茶/云朵/黑森林 | 三阶段（12 向弹幕 → 弹幕+召唤 → 蓄力激光） |

### 9.3 选敌优先级（刻意设计，别改坏）
`pickTargets(n, range)` 是**射程门控 + 分层 + 就近 + 锁定保持**四层规则：

1. **射程门控**：只考虑距玩家 ≤ 射程的目标（星芒 330px、流星 420px，见 `CFG.AIM.range`）。怪出场在屏幕边缘外，**不会隔屏开火**；进入射程才自动锁定。
2. **分层优先级**（`CFG.AIM.tier`）：最终 Boss(5) > 小 Boss(4) > 精英(3) > 普通怪(2) > 资源物(1)。层级用 `targetTier(e)` 判定，Boss 是否为"最终"看 `game.level >= CFG.LEVEL.total`。
3. **同层就近**：同层级内按距离由近到远。
4. **锁定保持** 0.45s（`CFG.AIM.stick`）：同层目标不会每帧来回摇摆；高层级目标出现时立刻切换。

资源物（星星水晶）刻意排在普通怪之后——它不会伤人，优先清掉正在咬你的怪更安全；想让资源优先把 `tier.res` 调成 2.5 即可。
范围伤害武器（星环/星辉结界/星爆）不走选敌逻辑，直接按范围命中敌人和资源物。
无目标时武器不计冷却（timer 停在 0），怪进圈的第一时间就开火。

### 9.4 震屏抗眩晕参数（动前必读）
高频命中走轻量通道：注入 0.22、软上限 0.28、同类节流 0.10s；只有受伤/精英击杀/Boss 事件保留满幅 0.78。参数在 `CFG.FEEL`。曾出现过两版翻车：衰减太快导致完全不震、衰减太慢导致后期看不清地图，改完必须实测峰值。

### 9.5 场景地面色
4 幕场景用 `ACTS[].ground/groundAlt` 铺地面，**不要**拿 `skyTop/skyBot` 渐变铺全屏——初版就是这么把草地画成浅蓝、森林画成粉色的。

### 9.6 其他坑速查

| 现象 | 原因 |
|---|---|
| 部署后没 UI 只有画面 | nginx 没配 mime.types |
| 换精灵后边缘发白 | 生图是假透明，重跑 `make_sprite.py` |
| 精灵裁切/位置飘 | 包围盒被羽化像素污染或脚底锚点没对齐 |
| vm 测试全 undefined | CDP/桩的返回层级少取了一层 |
| 测试失败但游戏正常 | 先查测试假设是否过时（历史上有 3 次都是测试错，不是代码错） |
| 手机上按钮点不准 | 触摸目标小于 44px，扩大 hit area 而不是只放大视觉 |
| 角色左右走朝向反了 | `render.js` 的 `flipX:player.faceX>0`（精灵默认朝左，往右走才翻转）；取反就会左走显示朝右 |
| 退出游戏后界面还在动 | 退出必须设 `game.state='menu'`；且别对 `#hud` 加 `.hidden`（其 !important 会压住 render 的 display:flex，重进游戏 HUD 出不来）|
| HUD 里的按钮点不到 | `#hud{pointer-events:none}` 会穿透整条 HUD，内部可交互元素必须单独设 `pointer-events:auto`（如暂停键） |
| 自动攻击隔屏打 Boss | 选敌必须先按射程过滤（`CFG.AIM.range`），再按层级排序；只按 tier 排序会让 Boss 无论多远都抢目标 |
| 怪进圈后迟迟不开火 | 无目标时不要重置武器 timer，否则白等一个 CD |
| 动效眩晕投诉 | 检查 `prefers-reduced-motion` 降级和震屏三档开关是否生效 |
