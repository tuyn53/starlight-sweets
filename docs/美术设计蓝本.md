## 0. v2 图标视觉语言（身份锚点，逐字复用，不许逐张自由发挥）

参考规范：本地技能 `pixel-game-icon`（取「类型三：技能法术」构图与三段光影，不套像素网格）、
`game-art-prompt-pack`（风格锚点逐字复用 / 先出锚点再批量 / 负面清单）。

| 维度 | v2 规范（硬约束） |
|---|---|
| 底衬 | **深色底衬**（每个主色对应一个深色调，如青→`#163a58`、粉红→`#5c2438`、紫→`#33235c`、樱粉→`#5a2848`），靠明暗对比把发光主体托起来；禁止亮色纯圆底 |
| 品质框 | 外层圆角方形 `rx=36` + 金色 `#ffd97a` 4px 描边 + 内圈 1.2px 细线 + 四角金色铆钉；禁止无框裸底 |
| 主体 | **具象能量体/物件**，一眼读出「这招干什么」；禁止抽象几何符号、禁止纯线性 icon |
| 明度 | 每个主体严格三段：左上亮面 / 主色 / 右下暗面；光源统一左上 45°，全套一致 |
| 辉光 | 中心渐亮（3 层同心低透明度圆）+ 边缘辉光点 + 粒子/拖尾，至少 2 类能量细节 |
| 动势 | 对称或强方向感（拖尾、放射、贯穿），禁止居中静止的静态符号 |
| 轮廓 | 深色闭合轮廓（沿用 `ART.outline #4a3d63`），小尺寸不糊 |
| 星光元素 | 每图标 ≥1 个星形/星点，呼应「甜星大作战」 |
| 配色 | 主色只从 `cfg.ART` 调色板取，深底取其暗部变体；单图标用色 ≤6 色 |

**风格锚点（生成/绘制每张图标时逐字复用，只替换主体变量）**：
> 甜星大作战 Q 版可爱幸存者游戏技能图标，深色底衬 + 金色圆角品质框 + 四角铆钉，
> 主体为具象星光能量体，三段明度（左上亮面/主色/右下暗面）、统一左上 45° 柔光，
> 深色闭合描边，中心渐亮辉光 + 边缘辉光点 + 星屑粒子，中心构图、对称或强方向感，
> 马卡龙配色、Q 版圆润、无文字、无平台阴影。

**负面清单（逐张自检）**：扁平单色平涂 / 纯白线性符号 / 亮色纯圆底 / 无框 / 抽象几何 /
中台 SaaS 风格 / 静止无动势 / 高饱和荧光 / 地面投影 / 文字水印 / 光影方向不一致。

| 锚点 | 内容 | 约束 |
|---|---|---|
| 角色语言 | 沿用现有 9 张精灵：Q 版二头身、大头大眼、深色描边、左上柔光源 | 新怪必须沿用，详见 art-direction-brief.md 公共锁定块 |
| 可读性红线 | 手机端卡牌图标显示区仅 ~30px | 缩到 30px 时「主体剪影 + 深底对比」必须可辨；细节允许丢失，剪影不许糊 |

图标规格：SVG 64×64 viewBox、`assets/icons/<key>.svg` 命名；接入方式 = `config.js` 的 `WEAPONS/PASSIVES` 增加 `icon:'assets/icons/xxx.svg'` 字段，卡牌 `.ci` 与 `.wicon` 改 `<img>` 渲染（emoji 保留为兜底）。

**本批视觉基准**：沿用 v2 的深底金框、具象星光主体与左上侧光。星芒、星爆、星链和星灵作为四种识别基准，其余图标用同一外框与能量点缀。

## 4. 技能释放动效规格（12 武器，三段式：前摇 → 释放 → 消散）

通用：释放瞬间玩家脚下白色星光环扩散 1 圈（8px，180ms，ease-out）；命中层 flash 闪白沿用现有 Juice；所有新粒子计入 MAX_PARTICLES=280。

| 武器 | 前摇（≤120ms） | 释放主体 | 消散 | 粒子 |
|---|---|---|---|---|
| 星芒 | 锁敌星点放大 | 3 星弹拖白尾直线 | 尾端小星散 | 每弹 4 |
| 星环 | 环加粗脉冲 | 星沿轨道切向飞出 | 轨迹淡出 | 0（常驻体） |
| 结界 | 罩面波纹上浮 | 周期净化脉冲环 | 环淡出 | 每脉冲 6 |
| 流星 | 天空小星下坠预备 | 流星斜砸 + 落点冲击星环 | 星屑跳散 | 每次 8 |
| 星爆 | 星核收缩 85ms | 8 向光针 + 冲击环 | 光针尾迹淡出 | 12 |
| 星潮 | 脚下蓄力圈 | 双层扩散冲击环（推开） | 波纹消散 | 10 |
| 星刃 | 出手星旋转 90° | 回旋镖弧线飞出/返回 | 弧线残影 | 4 |
| 星链 | 首目标闪星 | 锯齿电弧连跳（每跳衰减变细） | 电弧碎星 | 每跳 3 |
| 光棱 | 横线细光预热 | 全屏贯穿光束（先细后粗再收） | 光束两端散星 | 8 |
| 星尘雷 | 脚下布雷闪光 | 踩中：星形爆炸 + 环 | 星屑 | 每爆 10 |
| 星灵 | 星灵头顶生成圈 | 星灵自动索敌星弹 | 弹尾淡出 | 每弹 2 |

## 5. 素材清单与播放

| 类别 | 交付路径 | 规格 |
|---|---|---|
| 武器和被动图标 | [assets/icons](../assets/icons/) | 27 个独立 SVG，64×64 viewBox；在 30px 卡槽内使用 |
| 新怪物 | [assets/characters](../assets/characters/) | 8 张 512×512 真透明 WebP，脚底中心锚点；常规以 44px、精英以 52px 预览 |
| 既有主题 Boss 与守卫 | [assets/characters](../assets/characters/) | 沿用 boss、matcha、souffle、forest-queen、guard 五张已有精灵，主题 Boss 以 104px 预览 |
| 武器、怪物和 Boss 动效 | [assets/vfx](../assets/vfx/) | 23 套。每套有独立可编辑 SVG 和透明 WebP 图集，128×128 单格，6 列 × 3 行，每格一帧 |
| 资源索引 | [assets/manifest.json](../assets/manifest.json) · [motion.json](../assets/vfx/motion.json) | 素材来源、尺寸、锚点与时间轴 |

**Canvas 播放规格**：先解码单张图集。前摇、释放、消散依次对应三行，每行六帧。从 `motion.json` 读取各阶段持续时间，以阶段进度乘 6 取整并限制在 0–5，使用 `drawImage` 裁切。弹道类素材以图集中心定位，按目标方向旋转，碰撞位置与尺寸读取玩法数据。世界空间中的慢速池、星环、结界与星钟持续时循环使用释放行，离场时播放消散行。星链每跳按两个端点摆放，光棱沿瞄准轴拉伸；伤害、判定时机和实际范围以玩法逻辑为准。

**预警和性能**：Boss 图集的前摇行可在实际预警时间内匀速播放，危险区域须与判定一致。站位提示不得被命中特效、打击闪白或伤害数字覆盖。武器同发时优先保留弹道、落点和 Boss 预警，可省略图集自带星屑以外的附加粒子。粒子仍共用现有 280 粒上限；图集整张解码应在关卡加载阶段完成。
